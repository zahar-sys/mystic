# Структура проекта и организация модулей

zoxinaPodpiska — русскоязычный демонстрационный сайт из пяти страниц для сравнения подписок. Он не продаёт подписки, не принимает платежи и не отправляет данные посетителей.

- `dist/index.html`: главная страница и стандартное диалоговое окно выбора сервиса.
- `dist/chatgpt.html` и `dist/claude.html`: отдельные каталоги тарифов.
- `dist/compare.html`: сравнение характеристик тарифов с фильтрами.
- `dist/order.html`: локальная форма, расчёт стоимости и тестовое подтверждение.
- `dist/app.js`: варианты тарифов, месячные цены в USD, фильтрация, поведение диалогового окна и взаимодействие с формой.
- `dist/style.css`: общие адаптивные стили; шрифт Manrope загружается из Google Fonts.
- `.openai/hosting.json`: существующий идентификатор проекта Sites и каталог статических файлов.

В `dist/` находятся редактируемые исходники, а не временный результат сборки. В проекте нет менеджера пакетов, системы сборки или тестового фреймворка.

- `dist/assets/claude-code.svg`: локальный авторский значок кода для Claude Code, не официальный логотип.

- `dist/assets/claude-user.png`: изображение пользователя для карточек Claude и диалога на главной.

- `dist/assets/claude-dark.png`: обработанный вариант значка для тёмного фона карточки для главной.
