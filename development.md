# Команды разработки и проверки

Запускайте команды из корня репозитория:

- `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`: запуск локального предпросмотра.
- `node --check dist/app.js`: проверка синтаксиса JavaScript.
- `git diff --check`: проверка изменений в отслеживаемых файлах на ошибки пробелов и отступов.

Если запуск сервера заблокирован, откройте `dist/index.html` напрямую. Честно сообщайте об ограничениях проверки в браузере.
