# Стиль кода и правила именования

Используйте обычные HTML, CSS и JavaScript без фреймворков. В JavaScript соблюдайте отступ в два пробела, одинарные кавычки и точки с запятой. Именуйте функции в стиле camelCase, а CSS-классы — в стиле kebab-case. Не переформатируйте компактный HTML/CSS без необходимости для текущей задачи.

Сохраняйте русскоязычное содержимое, доступность элементов управления, видимый фокус клавиатуры, адаптивную навигацию и поддержку предпочтения уменьшенной анимации.
